# 🎓 AI-Powered Course Registration Assistant

An AI-powered student course registration assistant that helps students with:

- Course search
- Course eligibility checking
- Prerequisite verification
- Credit-limit checking
- Timetable conflict detection
- Course recommendations
- Registration guidance
- Course registration
- Course dropping
- Student profile management
- Natural-language academic assistance

---

## 🚀 Features

### 1. Student Login

Students can log into the system using their student ID and password.

### 2. AI Registration Assistant

The assistant understands natural-language questions such as:

- Can I register for Machine Learning?
- Recommend courses for me.
- Show my completed courses.
- Show my registered courses.
- Tell me about Artificial Intelligence.

---

### 3. Course Search

Students can:

- Search courses
- Filter by department
- View credits
- View semester
- View available seats
- View class schedules

---

### 4. Eligibility Checking

The system checks:

- Prerequisites
- Minimum grades
- Completed courses
- Existing registrations
- Course capacity
- Credit limits
- Timetable conflicts

---

### 5. Course Recommendations

The recommendation engine considers:

- Academic program
- Current semester
- Course availability
- Course relevance
- Eligibility

---

### 6. Registration

Students can:

- Check eligibility
- Register for courses
- View registered courses
- Drop courses

---

### 7. Student Profile

Students can view:

- Student ID
- Name
- Email
- Program
- Semester
- CGPA
- Completed credits
- Maximum credits
- Completed courses

---

### 8. Admin Module

The demo admin module allows courses to be added to the database.
